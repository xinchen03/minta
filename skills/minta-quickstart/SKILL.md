# Minta 3 分钟上手

1. **教它**：在 AI 对话里说一句你的经验，例如"以后回答前先说一句你试过什么"。
2. **确认**：打开 `http://127.0.0.1:8772` → 收件箱(Inbox) → 点"确认"。它变成你的永久记忆。
3. **用**：继续正常聊天。下次开会话时它自动带着这条记忆（SessionStart 注入 Context Pack）。

完。
